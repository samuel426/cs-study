## 학습 방식

1. 작은 주제 하나를 정해 개념을 공부한다.
2. 확인 문제 총 5개를 하나씩 풀고 답변에 대한 피드백을 받는다.
3. 이해한 내용과 수정한 생각을 Markdown으로 남긴다.
4. 목차와 현재 학습 상태를 갱신하고, 학습 기록이나 복습 내용을 커밋·푸시한다.
